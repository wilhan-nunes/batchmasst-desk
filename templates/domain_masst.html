batchMASST Desk

Batch spectral searches across biological domains. Search one spectrum or a whole batch across GNPS, then explore its microbial, plant, food, tissue, personal care, and microbiome matches. Node.js saves results to disk as they arrive; you can close this page and resume interrupted jobs.

2 · Search parameters

Library search always uses exact matching.

Workers process spectra in parallel. Default: 3 (range: 1–10).

More than 3 workers increases load on the shared FASST server. Please respect server capacity: keep 3 workers unless you need more, and reduce the number if requests slow down or fail.

Matches retain the best cosine / matched-peak score per sample file. Analog outputs also retain the best match per file and rounded mass shift, following the source branch.

3 · Domain outputs

Counts TSVs are always exported for selected domains. Select none for matches, library annotations, and dataset summaries only. Multiple domains also produce a combined tree.

Input is uploaded to your Node service; spectra are sent to FASST. Tree references download from the original repository. This app requires an internet connection for new searches and uncached references.
